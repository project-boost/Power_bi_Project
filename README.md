🏠 Airbnb Data Analysis Dashboard | Power BI
📌 Project Overview

This project presents an interactive Power BI dashboard built to analyze Airbnb listings data and extract meaningful insights related to pricing, availability, room types, hosts, and location trends.
The dashboard helps understand market behavior and supports data-driven decision making for both hosts and travelers.

🎯 Project Objectives

Analyze pricing variations across different locations

Understand availability and booking trends

Identify popular room types and property categories

Evaluate host activity and listing distribution

Visualize key metrics in a clear and interactive manner

🛠 Tools & Technologies

Power BI

DAX (Data Analysis Expressions)

Data Cleaning & Transformation

Interactive Data Visualization

📊 Key Insights

Price comparison by neighborhood and room type

Availability trends across different time periods

Distribution of listings by location

Analysis of entire homes, private rooms, and shared rooms

Host listing performance overview

📈 Dashboard Features

Interactive slicers and filters

User-friendly layout with professional design

Dynamic charts and KPIs

Easy navigation for quick insights
